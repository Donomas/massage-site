# Сайт массажиста

Для предпросмотра откройте `index.html` в браузере. Сайт написан на HTML, CSS и JavaScript. Устанавливать зависимости или собирать проект не нужно. Каждый раздел открывается по собственному адресу. Скрипт управляет загрузкой главной фотографии. Меню и содержание работают без JavaScript.

## Размещение на GitHub Pages

1. Загрузите все шесть файлов HTML, `styles.css`, `script.js`, `navigation.js`, `.nojekyll`, `sitemap.xml` и папку `assets` в корень выбранной ветки GitHub-репозитория.
2. В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, затем ветку (например, `main`) и папку **/(root)**. Сохраните.
3. Откройте адрес, показанный в Pages, и проверьте меню, фотографии и сценарий записи. Относительные пути работают и по адресу вида `username.github.io/repository/`.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Перед запуском записи и поискового продвижения

- В `contacts.html` замените каждый элемент `<span class="channel-status">…</span>` на ссылку вида `<a class="text-link channel-action" href="…">Открыть Telegram</a>`. Для Telegram и VK подставьте адреса, с которых начинается общение с клиентом. Для 2ГИС подставьте адрес карточки с маршрутом. Город и адрес уже указаны. При изменении адреса обновите видимый текст и JSON-LD в главной и контактах.
- Услуги без цен редактируются в `services.html` вместе с их JSON-LD. Абонементы добавляются в `programs.html` после подтверждения условий. Новости и акции редактируются в `news.html` и `offers.html`.
- Главная, виды массажа и контакты доступны для индексации и входят в `sitemap.xml`. Пустые новости, акции и абонементы сохраняют `noindex`. У всех страниц собственные canonical на действующий адрес GitHub Pages.
- Для Яндекс Вебмастера и Google Search Console добавьте ресурс `https://donomas.github.io/massage-site/` и подтвердите владение выданным сервисом HTML-файлом или метатегом. Затем отправьте `https://donomas.github.io/massage-site/sitemap.xml` и запросите обход трёх страниц.
- В Яндекс Вебмастере укажите регион «Ангарск» и страницу контактов. Добавьте или актуализируйте карточки Яндекс Бизнеса и 2ГИС с одинаковыми ФИО, адресом и ссылкой на сайт. Google Business Profile подключайте по доступности сервиса для региона. Соцсети и карточки свяжите с сайтом после получения их адресов.
- Отслеживайте индексирование, показы и переходы по запросам «массаж Ангарск», названиям процедур с городом и ФИО. Проверяйте скорость на телефоне. Полевые Core Web Vitals доступны после накопления посещений.
- `robots.txt` в подпапке GitHub Pages не управляет обходом сайта. Не добавляйте туда запреты в расчёте на ограничение индексации. Для пустых страниц используется `noindex` в HTML.
