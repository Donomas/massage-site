# Сайт массажиста

Для предпросмотра откройте `index.html` в браузере. Сайт написан на HTML, CSS и JavaScript. Устанавливать зависимости или собирать проект не нужно. Каждый раздел открывается по собственному адресу. Скрипт управляет загрузкой главной фотографии. Меню и содержание работают без JavaScript.

## Размещение на GitHub Pages

1. Загрузите все шесть файлов HTML, `styles.css`, `script.js`, `.nojekyll` и папку `assets` в корень выбранной ветки GitHub-репозитория.
2. В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, затем ветку (например, `main`) и папку **/(root)**. Сохраните.
3. Откройте адрес, показанный в Pages, и проверьте меню, фотографии и сценарий записи. Относительные пути работают и по адресу вида `username.github.io/repository/`.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Перед запуском записи и поискового продвижения

- В `contacts.html` замените каждый элемент `<span class="channel-status">…</span>` на ссылку вида `<a class="text-link channel-action" href="…">Открыть Telegram</a>`. Для Telegram и VK подставьте адреса, с которых начинается общение с клиентом. Для 2ГИС подставьте адрес карточки с маршрутом. Укажите подтверждённый город и место приёма.
- В `programs.html` замените примерные названия, состав и цены подтверждёнными условиями. Новости, акции и другие услуги редактируются в `news.html`, `offers.html` и `services.html` соответственно.
- Удаляйте тег `noindex` со страниц по мере готовности к индексации. Добавьте канонические адреса и карту готовых страниц после выбора постоянного URL. Для локальной разметки используйте подтверждённые сведения. После запуска проверьте сайт в Яндекс Вебмастере и Google Search Console, а скорость оцените на мобильных устройствах.
